## Overview

Habit tracking app with a React (Vite) frontend and an Express API: log daily habits, track streaks and see progress charts.

## Features

- Add habits and check them off daily
- Current streak and consistency tracking
- Progress page with simple charts
- Client/server split: React Router frontend, Express REST API

## Tech stack

JavaScript · React · Vite · Node.js · Express

## Getting started

```bash
cd server && npm install && node index.js     # API
cd client && npm install && npm run dev       # web app
```

## Project structure

`client/` React app (pages: Home, Habits, Progress) · `server/` Express API
